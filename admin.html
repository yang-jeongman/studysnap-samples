studysnap-samples 갤러리의 파일을 직접 올리고 지우는 화면입니다. 코드나 git 명령 없이 이 페이지에서 처리합니다.

① GitHub 연결

이 저장소(yang-jeongman/studysnap-samples)에 쓰기 권한이 있는 개인 액세스 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되고, GitHub 서버로만 직접 전송됩니다(다른 곳으로 전송되지 않음).

토큰 처음 만드는 방법 보기
1. github.com/settings/personal-access-tokens/new 접속(로그인 필요)
2. Repository access → Only select repositories → studysnap-samples 선택
3. Permissions → Contents → Read and write 로 설정
4. 하단 Generate token → 생성된 토큰(github_pat_...)을 복사해서 아래에 붙여넣기
5. 토큰은 한 번만 보여주므로 꼭 복사해두세요. 필요 없어지면 위 설정 페이지에서 언제든 삭제(폐기) 가능합니다.
