# StudySnap Samples - PDF to HTML Converter Gallery

**AI 기반 PDF 문서 자동 변환 샘플 갤러리**

---

## 📚 프로젝트 소개

StudySnap은 PDF 문서를 **인터랙티브 HTML**로 자동 변환하는 AI 기반 솔루션입니다.

### 주요 기능
- 🤖 Claude Vision API 기반 자동 인식
- 🎨 반응형 HTML 생성
- 📱 모바일 최적화
- 🖼️ 이미지 및 레이아웃 보존
- 🌍 다국어 번역 (선택)

## 🚀 사용 방법

### 1. 저장소 보기
- GitHub: https://github.com/yang-jeongman/studysnap-samples

### 2. 샘플 페이지 접속
- **[선거공보물 갤러리](./elections/)** - 지방선거 후보자 홍보페이지 목록

### 3. 각 페이지 열기
- 샘플을 클릭하면 **인터랙티브 HTML 페이지**가 열립니다
- 탭, 갤러리, 공약 정보 등을 확인할 수 있습니다
