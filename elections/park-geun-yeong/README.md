1. **경주시민 가정용 전기세 전면 무료** - 약 1,000억 규모
2. **중심상가 문화예술인촌으로 활력충전** - 250억 투자
3. **대릉원-동부사적지구 무차별 거리 확립** - 144억 규모
4. **동국대학교와 함께 가기** - 연간 1,000억 지원
5. **한수원 본사 경주시내 이전** - 국책사업비 활용
